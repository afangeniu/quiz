Gemini API Key Diperlukan untuk Generate AI

Agar soal yang dihasilkan benar-benar faktual, akurat, dan tidak mengada-ada sesuai topik maupun teks materi Anda, masukkan Google Gemini API Key gratis:

  1. Buka aistudio.google.com/apikey dan login akun Google.
  2. Klik Create API Key, lalu salin kodenya.
  3. Tempelkan pada kolom Google Gemini API Key di sebelah kiri dan klik Simpan.
